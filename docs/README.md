# THE NEGOTIATOR — FOUNDATION DOCUMENTATION

This package contains the foundational Markdown documentation for building The Negotiator.

## Core Idea

> **You ask. We negotiate.**

The customer submits a request:
> **“Can you negotiate this for me?”**

A human in-house Negotiator takes responsibility for the negotiation.

The Negotiator may have private, pre-negotiated commercial arrangements with businesses. Those arrangements are internal commercial assets and are not automatically disclosed to customers.

The customer receives the final negotiated offer and decides whether to accept it.

## Human-First
The initial operating model contains **human Negotiators only**. AI-assisted negotiation is not part of the initial service.
